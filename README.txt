# SELENIEL

아주 기본적인 개인 홈페이지 시작 파일입니다.

## 파일

- `index.html` : 홈페이지 구조
- `style.css` : 디자인
- `script.js` : 로고 클릭 및 화면 전환 기능
- `logo.png` : 사용할 로고 이미지

## 사용 방법

1. 원하는 로고 이미지를 `logo.png`라는 이름으로 이 폴더에 넣습니다.
2. `index.html`을 브라우저로 열면 됩니다.
3. 디자인은 `style.css`에서 자유롭게 수정합니다.
4. 기능은 `script.js`에서 수정합니다.

현재 기능:
- 첫 화면에 로고 표시
- 로고 클릭 → 메인 화면이 아래에서 위로 펼쳐짐
- 메인 화면의 SELENIEL 버튼 클릭 → 첫 화면으로 복귀
